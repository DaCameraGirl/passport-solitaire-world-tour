# Passport Solitaire — World Tour

Travel-themed Klondike solitaire. Win games to collect passport stamps from 55 destinations worldwide.

Built with Claude (Anthropic) — single-file vanilla HTML/CSS/JS.

## Destinations

55 cities across 7 regions, each with a custom hand-drawn SVG landmark on the card back:

- **Europe** (12): Paris, London, Rome, Barcelona, Amsterdam, Prague, Athens, Santorini, Lisbon, Vienna, Edinburgh, Istanbul
- **Asia** (12): Tokyo, Kyoto, Bangkok, Bali, Singapore, Hong Kong, Seoul, Shanghai, Mumbai, Kathmandu, Hanoi, Dubai
- **Africa** (8): Marrakech, Cairo, Cape Town, Nairobi, Zanzibar, Casablanca, Accra, Tunis
- **Americas** (9): Rio de Janeiro, New York, New Orleans, Havana, Mexico City, Buenos Aires, Cartagena, Machu Picchu, Vancouver
- **Oceania** (4): Sydney, Auckland, Fiji, Honolulu
- **Middle East** (4): Jerusalem, Petra, Muscat, Doha
- **Wild Cards** (6): Easter Island, Maldives, Svalbard, Faroe Islands, Patagonia

## Game Features

- Klondike solitaire with difficulty tiers (Easy / Medium / Hard)
- Custom SVG landmark card backs per destination
- Undo (Ctrl+Z), Auto-foundation (A)
- Timer + move counter
- Passport stamp collection with region progress
- Keyboard shortcuts
- Fully offline, single HTML file

## Play

Open `index.html` in any browser, or play at: https://dacameragirl.github.io/passport-solitaire-world-tour/
